# 52주 신고가 모멘텀 자동매매 (키움 OpenAPI+)

백테스트(2020.1~2026.9)에서 연평균 +30%, 최대낙폭 -37%였던 "01 52주 신고가 모멘텀" 전략을 그대로 자동화한 프로그램입니다.
과거 성과가 미래 수익을 보장하지 않습니다. **반드시 모의투자로 2~3개월 먼저 돌려보세요.**

## 전략

| 구분 | 내용 |
|---|---|
| 매수 조건 | 종가가 250일 최고가의 95% 이상 · 20일선 > 60일선 > 120일선 · 종가 > 20일선 · 주가 1,000원↑ · 20일 평균 거래대금 50억↑ |
| 시장 필터 | 해당 지수(코스피/코스닥) 종가 > 20일선, 20일선 > 60일선일 때만 신규 매수 |
| 매수 | 신호 다음날 아침 장전 동시호가 시장가 (거래대금 큰 순, 최대 10종목) |
| 매도 | 장중 매수가 -8% 즉시 손절 / 종가 20일선 이탈 시 다음날 아침 / 60거래일 경과 시 다음날 아침 |
| 자금 | 종목당 계좌 자산의 1/10 |

## 파일 구성

| 파일 | 역할 | 실행 환경 |
|---|---|---|
| `config.py` | 설정 (모의/실전, 투자비율, 손절 등) | — |
| `scan.py` | 장 마감 후 전 종목 스캔 → `data/signals_날짜.json` | 64비트 파이썬 3.11 |
| `trader.py` | 아침 주문 + 장중 손절 감시 | 32비트 파이썬 3.8 + 키움 |
| `trader_core.py` | 주문 판단 로직 | — |
| `kiwoom_broker.py` | 키움 OpenAPI+ 연결 | — |
| `test_flow.py` | 키움 없이 전체 흐름 테스트 | 아무 파이썬 |
| `run_scan.bat`, `run_trader.bat` | 작업 스케줄러용 실행 파일 | 윈도우 |

결과 기록: `data/state.json`(봇 보유 종목), `data/trades.csv`(매매 내역), `log/날짜.log`(하루 로그)

## 설치 (처음 한 번)

1. **키움 준비**
   - 키움증권 계좌 + 영웅문 ID
   - 키움 홈페이지 → 트레이딩채널 → Open API → 서비스 사용 등록 → OpenAPI+ 모듈 설치
   - 키움 홈페이지 → 모의투자 → 상시 모의투자 신청
2. **파이썬 2개 설치** (python.org → Downloads → Windows)
   - Python 3.11 **64-bit** (스캐너용) — 설치 첫 화면 "Add python.exe to PATH" 체크
   - Python 3.8 **32-bit** (키움용, "Windows installer (32-bit)")
3. **이 폴더를 PC로 받기**: GitHub → 저장소 → 브랜치 `condition-backtest` → Code → Download ZIP → 압축 풀고 `momentum_autotrade` 폴더를 예: `C:\autotrade` 로 복사
4. **패키지 설치** (명령 프롬프트에서)
   ```
   cd C:\autotrade
   py -3.11-64 -m pip install -r requirements_scan.txt
   py -3.8-32 -m pip install -r requirements_trader.txt
   ```
5. **동작 확인**
   ```
   py -3.11-64 test_flow.py          ← "모든 테스트 통과" 나오면 OK
   py -3.11-64 scan.py --limit 100   ← 100종목만 빠르게 스캔
   ```
6. **키움 자동로그인 설정**
   - `py -3.8-32 trader.py` 실행 → 로그인 창에서 **모의투자 접속** 체크 후 로그인
   - 작업표시줄 오른쪽 키움 아이콘 우클릭 → 계좌비밀번호 저장 → 비밀번호 입력·등록 → **AUTO 체크** (다음부터 자동 로그인)

## 매일 자동 실행 (윈도우 작업 스케줄러)

시작 → "작업 스케줄러" → 작업 만들기

| 작업 | 트리거 | 동작 |
|---|---|---|
| 스캔 | 매주 월~금 16:30 | `C:\autotrade\run_scan.bat` |
| 주문 | 매주 월~금 08:20 | `C:\autotrade\run_trader.bat` |

- "사용자가 로그온할 때만 실행" 선택 (키움은 화면이 필요)
- PC 절전 끄기: 설정 → 전원 → 절전 모드 "안 함"

## 하루 흐름

```
16:30  scan.py   전 종목 스캔 → 매수 후보 / 매도 대상 저장
08:20  trader.py 키움 로그인, 잔고 확인
08:45           매도 주문 → 매수 주문 (동시호가, 시장가)
09:03           체결 확인, 손절가 설정, 실시간 시세 등록
장중            현재가 ≤ 손절가 → 즉시 시장가 매도
15:25           결과 정리 후 자동 종료
```

## 안전장치

- `IS_REAL = False`(기본)인데 실전 서버에 로그인돼 있으면 **주문 없이 종료**
- `DRY_RUN = True` 로 두면 주문은 보내지 않고 로그만 기록
- 봇이 산 종목만 관리 (직접 산 종목은 매도하지 않고, 같은 종목은 새로 사지 않음)
- 같은 신호로 두 번 주문하지 않음, 5일 넘은 신호는 사용 안 함
- 휴장일 감지 시 주문 상태를 되돌리고 다음 거래일에 신호 재사용
- 09:30까지 체결 안 된 매수는 포지션에서 제외

## 실전 전환

모의투자 2~3개월 → `data/trades.csv`의 결과가 백테스트와 비슷한지 확인 → `config.py`에서

```python
IS_REAL = True
INVEST_RATIO = 0.3   # 처음엔 자산의 30%만
```

로그인 창에서 모의투자 체크 해제. 처음 몇 주는 매일 `log` 폴더를 확인하세요.

## 알려진 한계

- 장전 시장가 주문은 시가에 체결되지만, 상한가 갭이면 체결 안 될 수 있음
- 손절은 프로그램이 켜져 있을 때만 작동 (PC 꺼지면 손절 안 됨 → 영웅문 "자동감시주문"으로 -8% 스탑로스를 이중으로 걸어두는 것을 권장)
- 상장폐지·거래정지 종목은 로그에 "주의"로만 표시 → 직접 확인
