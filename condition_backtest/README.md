# 조건검색식 백테스트

키움 영웅문 조건검색식(일봉 기준 9종)을 파이썬으로 옮겨 2020년 이후 과거 데이터로 검증합니다.

- 결과: `results/README.md` (전략별 요약, 연도별 성과), `results/trades_*.csv` (전체 매매 내역)
- 실행: GitHub → Actions → "조건검색식 백테스트" → Run workflow (이 브랜치 선택)
- 로컬 실행: `pip install -r requirements.txt` 후 `python backtest.py` (빠른 테스트는 `--limit 50`)

| 번호 | 조건식 | 매도 규칙 |
|---|---|---|
| ① | 대시세 초입 (240일선 골든크로스 + 거래량 500% + 5% 상승) | +10% / -5% / 5일 |
| ①+ | ① + 60일 신고가 | 〃 |
| ② | 일목균형표 눌림 | +15% / -7% / 20일 |
| ③ | 20일선 눌림목 | 〃 |
| ④ | 이평선 수렴 (주봉 신고가·정배열 + 일봉 이평 밀집) | 〃 |
| ⑤ | 신고가 돌파 4% (코스닥, 시총 700억↑) | +10% / -5% / 5일 |
| ⑥ | 데이 주도주 (60일 신고가 + 거래대금 800억) | 〃 |
| ⑧ | 스윙 대응형 (10% 급등 후 20일선 눌림) | +15% / -7% / 20일 |
| ⑨ | 스윙 예측형 (대량거래 후 거래량 급감) | 〃 |
| ⑪ | 저PBR 급등 (PBR 0.3 이하) | 〃 |

분봉 조건(⑦ 3분봉 거래량, ⑩ 1분봉 스캘핑)은 무료 분봉 데이터가 없어 제외했습니다.
