# 적립매수(DCA) 전략 백테스트 대시보드

주식/ETF의 과거 시세로 다양한 적립매수(DCA) 타이밍 전략을 백테스트하고, 종목별 최적 전략을 찾아주는 웹앱입니다.

## 구성

- `public/` — 프런트엔드 (정적 HTML/CSS/JS, 백엔드 프레임워크 없음)
- `netlify/functions/history.mts` — Yahoo Finance(우선)와 Stooq(대체)에서 일별 시세를 가져오는 서버리스 함수. 브라우저는 CORS 문제로 이 API들을 직접 호출할 수 없어서 프록시가 필요합니다.
- `netlify/functions/search.mts` — 종목명/코드로 티커를 검색하는 서버리스 함수(Yahoo Finance Search API 프록시).
- `netlify.toml` — Netlify 빌드 설정 (`public`을 정적 배포 루트로, `netlify/functions`를 함수 디렉터리로 지정)

## 기능

- 미국(VUG, AAPL 등)·한국(005930.KS 등) 주식/ETF 검색 및 선택
- 백테스트 기간(1/3/5/10년/최대 또는 직접 지정), 월 납입액, 월급날, 거래비용(%) 설정
- 14종 내장 전략(매일/매주 금요일/매월 특정일·첫거래일·마지막거래일/MA10·50·100·200 이하/RSI(14) 30·20 이하/전일대비 -3%·-5% 급락 시)
- 기준 스케줄 + 이동평균·RSI·전일대비 등락률 조건을 조합하는 "직접 조건 추가" 커스텀 전략 빌더
- 수익률 순위표, 월급날 기준 대비 비교, 수익률 추이 차트(호버 툴팁 포함), 결과 링크 공유
- "종목별 최적 전략 비교" 탭 — 여러 종목을 한 번에 백테스트해 종목별 최적 전략을 정렬해서 보여줌

## 배포 방법 (Netlify)

이미 Netlify에 `dca-backtest-dashboard`라는 이름의 프로젝트(site id: `511678c9-7581-4ad5-825e-568f1c18cdc7`)가 생성되어 있고, 방문자 접근 제한(SSO/비밀번호)도 꺼져 있어 공개 접속이 가능하도록 설정되어 있습니다. **다만 실제 코드 배포(deploy)는 아직 완료되지 않았습니다.**

컴퓨터(Node.js 설치되어 있는 환경)에서 아래 명령을 이 프로젝트 폴더 안에서 실행하면 1~2분 안에 배포가 끝납니다:

```bash
npx netlify-cli deploy --prod --site 511678c9-7581-4ad5-825e-568f1c18cdc7
```

- 처음 실행하면 브라우저가 열리며 Netlify 로그인을 요청합니다. 이 대시보드를 만든 Netlify 계정(wonderer1004@gmail.com, Google 로그인)으로 로그인하세요.
- 로그인 후 자동으로 `public/`과 `netlify/functions/`가 함께 빌드·배포됩니다 (`netlify.toml` 설정을 그대로 사용).
- 배포가 끝나면 `https://dca-backtest-dashboard.netlify.app` 에서 바로 접속 가능합니다.

이후 코드를 수정할 때도 같은 명령을 다시 실행하면 됩니다.

## 로컬에서 미리보기 (선택)

```bash
npx netlify-cli dev
```

`netlify dev`는 정적 파일과 서버리스 함수(`/api/search`, `/api/history`)를 함께 로컬에서 구동합니다.

## 참고

- 가격 데이터는 Yahoo Finance(1순위)와 Stooq(대체)에서 무료로 가져오며, 배당·액면분할을 반영한 수정주가(adjusted close) 기준으로 계산합니다.
- 조건(이동평균/RSI/급락 등)이 그 달에 한 번도 충족되지 않으면 그 달의 납입액은 이월되지 않고 투자되지 않은 것으로 처리됩니다. (스크린샷 참고 앱의 RSI(14) 20 이하 전략처럼, 조건이 거의 발생하지 않으면 투자금과 수익률이 0이 될 수 있습니다.)
- 과거 수익률은 미래 수익률을 보장하지 않으며, 세금은 반영되지 않습니다.
